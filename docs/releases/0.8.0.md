# StratAgent 0.8.0 — Developer Preview

Describe your project. Design its agent workspace. Approve what gets installed.

StratAgent combines project-aware roles, existing-host model orchestration,
reviewed skill/MCP discovery and exact approval with portable workspace outputs.
It runs locally and needs no separate LLM API key for the existing-host flow.

## What ships

- Versioned Claude Code, Codex, Antigravity and generic renderers, including a
  Claude reserved-skill-name compatibility fix.
- Reviewed apply/update/remove with ownership, drift checks, provenance and
  recoverable transactions.
- Offline `doctor`, including missing-PyYAML installation diagnosis.
- Six native OS/Python CI jobs, source/installed tests, CLI/lifecycle acceptance,
  repeatable source/archive-to-wheel builds and offline package acceptance.
- Checksums, complete wheel inventories, distribution SBOMs and independently
  verifiable GitHub release-workflow provenance.
- [Support](https://github.com/etrkk5/stratagent/blob/main/SUPPORT.md),
  [private security reports](https://github.com/etrkk5/stratagent/security/advisories/new)
  and a scheduled read-only declared-dependency advisory check.

## Install and verify

Python 3.11+ is required. See the
[download verification/install guide](https://github.com/etrkk5/stratagent/blob/main/docs/publishing.md#verify-and-install)
and [offline walkthrough](https://github.com/etrkk5/stratagent/blob/main/docs/demo-0.8.0.md).

The direct application wheel and source archive are canonical Ubuntu/Python 3.11
CI outputs. Each of the six named ZIPs contains its platform/Python's application
wheel, PyYAML wheel, source archive, SBOM, local receipt and checksums.
`RELEASE-MANIFEST.json` identifies the exact source commit and successful main CI;
top-level `SHA256SUMS` covers eight payload assets and the manifest. Verify signed
GitHub provenance too. Inner receipts retain `signed: false`; the external signed
workflow attestation is a separate layer.

PyPI publishing is a separate manual operation requiring the maintainer's PyPI
Trusted Publisher configuration. A GitHub release alone does not make
`pip install stratagent-cli` available.

## Preview limitations

This is not a production/GA release. Host formats follow documentation; native
runtime coverage varies. Fresh Claude Code/Antigravity sessions, 30 human reviews
and independent installation trials were explicitly waived, not performed or
passed. OS CI does not certify native host behavior or usefulness.

StratAgent does not launch agents, activate MCP servers or execute arbitrary
third-party code automatically. Findings, hashes and attestations do not guarantee
safety. The SBOM excludes native-library/OS and vendored build-tool closure.
Network filesystems and physical power loss remain outside transaction assurance.
See [readiness](https://github.com/etrkk5/stratagent/blob/main/docs/release-readiness.md)
and [rollback](https://github.com/etrkk5/stratagent/blob/main/docs/releasing.md#roll-back-without-losing-project-state).
